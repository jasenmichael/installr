# CLI

`installr` reads the config, validates it, and writes `install.sh`. The generated script is what end users run.

## Exit codes

| Code | Meaning |
| --- | --- |
| 0 | Config is valid. With `--check`, nothing is written. |
| 1 | Invalid config. stderr names the field (`APP_NAME`, `SOURCE`, `BIN`, `GH_ASSET_URL`, `REPO_URL`, or the unknown key). |
| 2 | Usage error (bad flag or missing flag argument). |

## Flags and env

Precedence for the config path: `--config`, then `INSTALLR_CONFIG`, then `./installr.conf`.

Precedence for the output path: `--output`, then `INSTALLR_OUTPUT`, then `INSTALL_SCRIPT` in the config, then `install.sh`.

| Flag / env | Meaning |
| --- | --- |
| `--config PATH` / `INSTALLR_CONFIG` | Config file to read. |
| `--output PATH` / `INSTALLR_OUTPUT` | Path to write the install script. |
| `--check` | Validate only. Exit 0 writes nothing. Exit 1 names the bad field. |

A valid run without `--check` writes the install script.

## Curl

`./src/installr.sh` sources `lib/` and only works as a file on disk in a checkout. The one-file build is `bin/installr`, produced by `script/bundle.sh`. That file is what `curl … | bash -s --` runs. It does not source `lib/` or `share/`. See [STACK.md](STACK.md) and [README.md](README.md).

```bash
script/bundle.sh
curl -fsSL https://github.com/jasenmichael/installr/raw/main/bin/installr | bash -s -- --config ./installr.conf
curl -fsSL https://github.com/jasenmichael/installr/raw/main/bin/installr | bash -s -- --check --config ./installr.conf
```

## install.sh

Generated by installr. End users run it with `./install.sh` or `curl …/install.sh | bash`.

| Flag | Meaning |
| --- | --- |
| `--local` | Install under the local prefix. Fails when the author locked `SCOPE=global`. |
| `--global` | Install under the global prefix. Uses `sudo` when not root. Fails when the author locked `SCOPE=local`. |
| `--yes` | Replace an existing app config without a prompt. |

When the author omits `SCOPE`, install defaults to local and both flags work. When `SCOPE=global`, running with no flag installs global. `LOCAL_PREFIX` and `GLOBAL_PREFIX` only set the directories.

When the destination config exists, stdin is not a terminal, and `--yes` was not passed, the existing file stays and `CONFIG_INSTALLED` is `no`. When stdin is a terminal, `install.sh` prompts `Replace <path>? [y/N]`. `y`, `Y`, or `yes` replaces it.

Exit non-zero on unknown OS or arch, missing dependency, missing binary path for the detected platform, fetch failure, or a forbidden `--local` / `--global` under an author `SCOPE` lock.

## uninstall.sh

Written into the app dir by a successful install. Reads `install.log` next to itself. Exit 1 and delete nothing when the log is missing or `APP_DIR` does not match the script’s directory. Otherwise removes the symlink, removes the config only when `CONFIG_INSTALLED=yes`, and removes the app dir last. Uses `sudo` when `SUDO=yes`. No second prompt.
